# Scientific Dataset Release Policy

## Dataset states

```text
DRAFT → VALIDATED → REVIEWED → PUBLISHED
                         ↓
                      RETRACTED
```

`RETRACTED` preserves the historical dataset and records the reason; it does not erase evidence.

## Required release metadata

Every released dataset must identify:

- dataset ID and semantic version;
- origin (`EXPERIMENTAL`, `SIMULATION`, `DERIVED`, `AI_ANALYSIS`);
- SHA-256 content hash;
- storage reference;
- experiment IDs and provenance references;
- instrument/calibration references when applicable;
- processing and analysis version;
- software Git commit when generated by IUVFES;
- validation status;
- known limitations;
- responsible researcher/reviewer.

## Publication rule

A dataset is not considered scientific reference material merely because it exists in the application. Publication requires review and an appropriate persistent identifier/repository process. The application records the external identifier after assignment.

## Corrections

Never overwrite a published dataset. Create a new version and link it to the previous version with a provenance relationship and a human-readable change reason.
