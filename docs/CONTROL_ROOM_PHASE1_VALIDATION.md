# Control Room Phase 1 Validation

The Control Room now consumes the server-side closed-loop session lifecycle rather than the legacy batch playback path.

## Runtime path

`closedLoop.create -> closedLoop.start -> closedLoop.step -> CausalFrame -> Control Room`

Each step is one simulator timestep. Pause prevents engine advancement; resume continues the same session.

## Data source

The dashboard reads `CausalFrame.sensorAfter`, `CausalFrame.controller`, `CausalFrame.materialInventory`, and `CausalFrame.safety`.

No production sensor value is generated by the UI.

## Validation boundary

The model remains simulation data and requires laboratory calibration/validation before scientific or engineering claims.
