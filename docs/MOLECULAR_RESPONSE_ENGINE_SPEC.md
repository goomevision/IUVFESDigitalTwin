# IUVFES Molecular Response Engine — Scientific Boundary Specification

## Purpose

This document defines how the proposed "Molecular Counter" is incorporated into IUVFES without turning an unvalidated hypothesis into a physical fact.

## Core principle

Ultrasonic frequency is an experimental control variable. A measured response peak is an observed response. A fitted peak is a model result. Neither becomes a molecular resonance claim automatically.

The allowed evidence chain is:

```text
OPERATING CONDITION
    -> ACOUSTIC / PROCESS RESPONSE
    -> MASS TRANSFER / RELEASED MASS
    -> ANALYTICAL MEASUREMENT
    -> COMPOUND-RESPONSE ASSOCIATION
    -> QUANTITATIVE INFERENCE
    -> VALIDATION
```

## Explicit prohibitions

1. Literature operating frequency MUST NOT automatically populate `f0`.
2. A frequency-sweep peak MUST NOT automatically be labelled a molecular resonance.
3. A reduced-order selectivity factor MUST NOT be presented as measured molecular selectivity.
4. Estimated molecule count MUST be derived from measured/validated mass or concentration and molecular weight, not from ultrasonic frequency alone.
5. Four universal frequency bands MUST NOT be hard-coded as universal material physics.
6. Simulation results MUST remain distinguishable from laboratory measurements.
7. Conflicting literature must remain visible and reviewable.

## Response model

A sweep records raw response points:

```text
frequency -> yield / mass released / mass rate / concentration
```

Peak analysis can produce:

```text
f_peak
bandwidth
amplitude
prominence
SNR
fit quality
confidence
```

These values belong to the `DETECTED_PEAK` layer and describe the measured response curve.

## Selectivity hypothesis

A Lorentzian or other response function may be used as a reduced-order model:

`S(f) = 1 / (1 + ((f - f0) / bandwidth)^2)`

The model parameters must remain classified as `HYPOTHESIS`, `MODEL_FIT`, or `VALIDATED`. They are not hard-coded molecular constants.

## Molecular quantity calculation

If an analytical method supplies mass `m_i` and molecular weight `MW_i`:

`n_i = m_i / MW_i`

`N_i = n_i * N_A`

where `N_A` is Avogadro's constant.

The resulting quantity is labelled **derived molecular quantity**. It is not a direct ultrasonic molecule count.

For concentration `C_i` in a known volume `V`:

`m_i = C_i * V`

before applying the molar conversion.

## Analytical bridge

The Molecular Response Engine must support evidence from analytical instruments such as GC-MS, HPLC, LC-MS, NMR, spectroscopy, or validated gravimetric measurements. The analytical record must preserve instrument, method, uncertainty, provenance, and experiment linkage.

## Response-to-compound learning

IUVFES may learn associations such as:

```text
frequency / acoustic conditions
        -> measured process response
        -> analytical compound response
```

Possible association methods include correlation, regression, multivariate analysis, and expert review. Every association receives a status:

- HYPOTHESIS
- MODEL_FIT
- SUPPORTED
- CONTRADICTED

## Material fingerprint evolution

A material profile should evolve by evidence:

```text
v001 literature baseline
       |
       v
v002 laboratory sweep
       |
       v
v003 analytical correlation
       |
       v
v004 independent validation
```

Old versions remain immutable and traceable.

## Unknown-first behavior

When `f0`, bandwidth, Q-factor, compound association, or another parameter is not supported by evidence, the value remains `UNKNOWN`/`null`. The system should create or update a `MaterialGap` rather than inventing a default physical value.

## Experimental planner

The planner should select experiments based on information gain, uncertainty reduction, feasibility, and scientific priority. It must not optimize solely for yield.

A useful next experiment may be one that distinguishes competing hypotheses, even if its immediate extraction yield is low.

## Control-room display rule

The UI must distinguish at minimum:

- **OBSERVED** — measured or directly reported evidence.
- **SIMULATION** — generated by the simulation engine.
- **DERIVED** — calculated from measured inputs.
- **HYPOTHESIS** — proposed model assumption.
- **MODEL FIT** — fitted to data.
- **VALIDATED** — supported by independent validation evidence.
- **UNKNOWN** — no sufficient evidence.

## Scientific warning shown to operators

> Frequency-response patterns are model and experiment dependent. IUVFES does not infer molecular identity from frequency alone. Molecular composition claims require analytical evidence and validation.

## Scope

This specification extends the existing scientific data foundation. It does not replace the closed-loop process engine, hardware configuration layer, operator input layer, provenance system, Material Knowledge Base, or report/journal pipeline.
